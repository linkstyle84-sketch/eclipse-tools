이클립스 헤스5 딸깍팀 길드원 안내 — 공유 링크 만들기
====================================================

이미 가입한 길드원에게 공지방 · 디코 · 분배시트를 안내하는 페이지입니다.
시트·드라이브 권한은 필요 없습니다.

1. https://sheets.new 로 새 시트를 연다
2. 확장 프로그램 → Apps Script
3. Code.gs 내용을 전부 지우고 이 폴더의 Code.gs 를 붙여넣는다
4. 왼쪽 + → HTML 파일, 이름을 Index 로
5. Index.html 내용을 붙여넣고 저장(Ctrl+S)
   (미리보기.html 과 같은 내용이면 된다)
6. 실행 버튼은 누르지 말고
   배포 → 새 배포 → 유형: 웹 앱
   - 실행 계정: 나
   - 액세스 권한: 모든 사용자
7. 배포 후 나온 URL을 단톡방·공지방에 올린다

권한 창이 또 뜨면
- "차단된 앱" 이면 창을 닫고 새 시트(sheets.new)에서 다시
- "확인되지 않은 앱" 이면 고급 → (프로젝트 이름)(으)로 이동 을 누른다

로컬에서만 볼 때는 미리보기.html 을 브라우저로 열면 됩니다.
카톡에 파일 자체를 보내면 폰에서 잘 안 열리니, 꼭 웹 앱 링크를 쓰세요.
