결속 — 개요
===========

결속은 재건이 끝난 성물에 초월·무기 외형 카드를 꽂아
포인트를 모으고, 구간마다 결속 효과를 켜는 컨텐츠입니다.

구성
- 성물: 초월의 성물 / 외형의 성물 / 황금의 성물 / 경험의 성물
  미해금: 잠재력의 성물 / 클레온의 성물 / 권능의 성물 / 자격의 성물
  (게임 업데이트 전. 데이터 없음)
- 카드: 초월, 무기 외형 (장착·프리셋 적용 카드는 결속 불가)
- 슬롯: 15칸. LV=성물 해금 레벨, 등급 글=카드 최소 등급. 초월·외형·황금·경험은 배치가 같음. 중복 결속 불가
- 포인트: 결속된 카드 단계 합산 + 결속 조합 추가 포인트
- 등급 카운트: 희귀 / 영웅 / 전설 / 신화

작업 순서
1. 성물 재건 완료
2. 슬롯 조건에 맞는 카드 결속
3. 단계 합산으로 포인트 확보
4. 결속 조합으로 추가 포인트
5. 일정 포인트 달성 시 결속 효과

화면
- 왼쪽: 초월 / 무기 외형 / 스킨 / 결속
- 가운데: 선택한 성물 + 결속 슬롯
- 오른쪽: 결속 효과 / 초월 / 무기 외형
- 아래: 결속 조합 / 일괄 해제 / 자동 결속
