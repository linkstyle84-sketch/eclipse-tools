결속 슬롯
=========

슬롯에 적힌 LV = 그 성물을 이 레벨까지 올리면 해금.
슬롯 아래 글 = 넣을 수 있는 카드 최소 등급.
- 희귀 이상: 희귀 / 영웅 / 전설 / 신화
- 영웅 이상: 영웅 / 전설 / 신화
- 전설 이상: 전설 / 신화
초월 카드, 무기 외형 카드 둘 다 가능. 장착·프리셋 카드는 불가. 중복 결속 불가.

초월·외형·황금·경험은 슬롯 15개가 같고 해금 레벨도 같다.
캡처 당시 성물 레벨만 다름 (초월·외형 Lv.9 / 황금 Lv.8 / 경험 Lv.7).

배치 (가운데 성물 기준)
왼쪽 2×2          오른쪽 2×2
희귀 / 희귀       희귀 / 희귀(또는 Lv.9)
희귀 / 희귀       Lv.11 / Lv.13

아래 왼쪽                가운데         아래 오른쪽
Lv.15 / Lv.16 / Lv.17    Lv.21         Lv.18 / Lv.19 / Lv.20

해금
- 희귀 이상 8칸: 시작 2칸 + Lv.3 / 5 / 7 / 9 / 11 / 13
- 영웅 이상 6칸: Lv.15 / 16 / 17 / 18 / 19 / 20
- 전설 이상 1칸: Lv.21

캡처에서 열린 희귀 칸은 LV가 안 보임.
- 경험 Lv.7: 5칸 열림 (시작 2 + 3·5·7)
- 황금 Lv.8: 5칸 열림 (다음이 Lv.9)
- 초월·외형 Lv.9: 6칸 열림 (Lv.9 칸까지)
