결속 데이터 — 받는 방법
========================

유저가 가장 알고 싶은 것
- 결속 조합으로 등급마다 포인트를 얼마나 더 받나
- 그 조합에 어떤 초월 / 무기 외형 카드가 들어가나

문제
- 결속 조합 목록에는 포인트와 세로 카드만 있고, 카드 이름이 없다.

쓰는 방법
- 한장 / 처음 보는 카드: 상세 창을 연 채로 캡처. 이름·정사각 초상화·+p가 필요함.
- 페어: 이미 한장에 있는 카드면 텍스트 목록이 더 낫다. 줄마다 카드 이름과 강수만.
- 페어에 처음 나오는 카드만 상세 한 장.

HTML 이미지
- 오른쪽 세로형 카드는 쓰지 않는다.
- 카드 이름 옆에 있는 정사각 초상화를 잘라 쓴다.
- 얼굴이 크고 크기가 같아서 목록·합계 화면에 맞다.

캡처 순서
1. 결속 조합 창 → 희귀 / 영웅 / 전설 / 신화
2. 각 줄의 카드를 눌러 상세를 연다
3. 이름과 정사각 초상화가 보이게 찍는다
4. 다음 줄로 넘어간다

한 조합에 카드가 여러 장이면 카드마다 한 장씩 찍는다.

--------------------------------
한장 공유
--------------------------------
한장(1장짜리)은 초월 / 외형 / 황금 / 경험 성물이 같은 카드.
초월의 성물 한장은 100% 등록됨. 다른 성물에서 한장은 다시 안 받음.
성물마다 다른 건 2장·3장 페어 (1강 / 3강 / 5강)뿐.

--------------------------------
결속 효과
--------------------------------
구간을 달성하면 그 줄 스탯이 캐릭터에 더해짐. 연 구간은 누적.
성물마다 희귀 / 영웅 / 전설 / 신화 트랙이 따로 있음.
5포인트마다. 초월·외형·황금·경험 5~150 등록.

미해금 (게임 업데이트 전. 데이터 없음)
- 잠재력의 성물
- 클레온의 성물
- 권능의 성물
- 자격의 성물
해금되면 조합(한장 공유 여부·페어) + 결속 효과 + 슬롯을 이어서 받음.

--------------------------------
슬롯
--------------------------------
슬롯 LV = 성물 해금 레벨. 아래 등급 글 = 넣을 수 있는 카드 최소 등급.
초월 카드·무기 외형 카드 둘 다 가능.
초월·외형·황금·경험은 15칸 배치·해금 레벨이 같음.
저장: 슬롯\
