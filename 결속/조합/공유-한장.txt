결속 조합 — 한장 공유
====================

한장(1장짜리)은 성물마다 다시 받지 않음.
초월의 성물에 등록된 한장이 아래 성물에서도 같다.

공유
- 초월의 성물
- 외형의 성물
- 황금의 성물
- 경험의 성물

한장 목록 (초월의성물 폴더)
- 희귀 44장  → 조합\초월의성물\희귀.txt
- 영웅 68장  → 조합\초월의성물\영웅.txt
- 전설 28장  → 조합\초월의성물\전설.txt
- 신화 6장   → 조합\초월의성물\신화.txt

한장 포인트 (줄마다)
- 희귀: [희귀] +5p
- 영웅: [희귀] +3p / [영웅] +5p
- 전설: [영웅] +3p / [전설] +5p
- 신화: [전설] +3p / [신화] +5p

성물마다 다른 것
- 2장·3장 페어 (1강 / 3강 / 5강)
- 페어 포인트는 성물·등급 줄을 보고 적음

잠재력의 성물 / 클레온의 성물 / 권능의 성물 / 자격의 성물
- 게임 업데이트 전. 해금 안 됨. 데이터 없음.
- 해금되면 한장 공유 여부와 페어를 이어서 받음.
