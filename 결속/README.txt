이클립스 툴 — 결속
==================

잠재력·권능과 별도인 결속 작업 폴더입니다.
이후 HTML·배포 작업도 이 폴더에서만 진행합니다.

잠재력
- 태초 6개 + 변화 6개 근원
- 셋팅 비교 시연 페이지

권능
- 성혼 / 성유물 장착 · 감정 · 각인 · 합성 · 변환 · 제작 · 분해

결속
- 재건된 성물에 초월·무기 외형 카드를 꽂아 포인트·효과를 켬
- 성물: 초월 / 외형 / 황금 / 경험 (등록 완료)
- 미해금: 잠재력 / 클레온 / 권능 / 자격 (게임 업데이트 전)

유저가 보는 핵심
- 결속 조합으로 등급별 추가 포인트를 얼마나 챙기는지
- 조합에 들어가는 초월·무기 외형 카드 (이름 + 그림)

초기 모델
- Index.html  슬롯 수 + 등급 체크 + 1·3·5강 + 없는 카드 클릭 제외
- data.js / app.js

데이터
- 룰\      : 가이드 1~4쪽 규칙
- 가이드\  : 인게임 가이드 1~4쪽 캡처
- 슬롯\    : 성물별 결속 슬롯 화면 (LV·등급 조건)
- 데이터\  : 받는 방법
- 카드\    : 초월 / 무기외형 도감 이미지 (파일 이름 = 카드 이름)
- 조합\    : 성물·등급별 조합 정리
- 효과\    : 성물·등급별 결속 효과 (5~150)
