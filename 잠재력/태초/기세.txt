이클립스 잠재력 — 태초 / 기세
============================

등급별 강화 최대 레벨
- 일반 Lv.20
- 고급 Lv.40
- 희귀 Lv.60
- 영웅 Lv.80
- 전설 Lv.100

확률: 일반 7.9% / 고급 3.5% / 희귀 1% / 영웅 0.08% / 전설 0.02%

옵션                  일반            고급            희귀            영웅             전설
최대 HP               500 / 7.9%      1500 / 3.5%     3000 / 1%       5000 / 0.08%     7499 / 0.02%
최대 MP               1600 / 7.9%     4800 / 3.5%     9600 / 1%       16000 / 0.08%    24000 / 0.02%
HP 회복               20 / 7.9%       40 / 3.5%       60 / 1%         80 / 0.08%       100 / 0.02%
MP 회복               20 / 7.9%       40 / 3.5%       60 / 1%         80 / 0.08%       100 / 0.02%
물약 회복률           0.1% / 7.9%     0.3% / 3.5%     0.6% / 1%       1% / 0.08%       1.5% / 0.02%
물약 최대 소지량      20 / 7.9%       40 / 3.5%       60 / 1%         80 / 0.08%       100 / 0.02%
경험치 획득량 증가    0.33% / 7.9%    1% / 3.5%       2% / 1%         3.33% / 0.08%    5% / 0.02%
골드 획득량 증가      1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%

참고
- 기세는 생존·회복·획득량 계열. 옵션 8종, 등급별 확률은 다른 태초 근원과 동일.
- 일반 최대 HP는 화면이 5000처럼 보이지만, 고급 1500 / 희귀 3000 / 영웅 5000 / 전설 7499
  및 다른 옵션의 1·3·6·10·15 배율에 맞춰 500으로 정리함.
- 영웅 최대 MP는 화면 표기가 1,6000, 전설은 2,4000으로 보임.
  일반 1600 → 고급 4800 → 희귀 9600 배율에 맞춰 16000 / 24000으로 정리함.
- 전설 최대 HP는 화면 숫자 그대로 7499 (7500이 아님).
