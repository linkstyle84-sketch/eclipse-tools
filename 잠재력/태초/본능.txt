이클립스 잠재력 — 태초 / 본능
============================

등급별 강화 최대 레벨
- 일반 Lv.20
- 고급 Lv.40
- 희귀 Lv.60
- 영웅 Lv.80
- 전설 Lv.100

옵션은 등급 최대 레벨까지 강화해야 최대값에 도달합니다.

확률 합계: 일반 8×7.9% + 고급 8×3.5% + 희귀 8×1% + 영웅 8×0.08% + 전설 8×0.02% = 100%

옵션            일반          고급          희귀          영웅            전설
                값 / 확률     값 / 확률     값 / 확률     값 / 확률       값 / 확률
근거리 명중     20 / 7.9%     60 / 3.5%     120 / 1%      2000 / 0.08%    3000 / 0.02%
원거리 명중     20 / 7.9%     60 / 3.5%     120 / 1%      2000 / 0.08%    3000 / 0.02%
마법 명중       20 / 7.9%     60 / 3.5%     120 / 1%      2000 / 0.08%    3000 / 0.02%
근거리 공격력   20 / 7.9%     40 / 3.5%     72 / 1%       1200 / 0.08%    1800 / 0.02%
원거리 공격력   20 / 7.9%     40 / 3.5%     72 / 1%       1200 / 0.08%    1800 / 0.02%
마법 공격력     20 / 7.9%     40 / 3.5%     72 / 1%       1200 / 0.08%    1800 / 0.02%
PvE 명중        40 / 7.9%     120 / 3.5%    240 / 1%      4000 / 0.08%    6000 / 0.02%
PvE 공격력      24 / 7.9%     72 / 3.5%     144 / 1%      2400 / 0.08%    3600 / 0.02%

참고
- 희귀 PvE 명중/공격력은 화면 OCR이 2400·1440으로 읽혔으나,
  같은 등급 다른 옵션 비율(명중의 2배, 공격력의 2배)에 맞춰 240·144로 정리함.
- 영웅·전설은 화면 숫자 그대로 2000/3000 단위를 사용함.
