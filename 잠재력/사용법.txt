이클립스 잠재력 시연 — 배포 링크에서 그림 나오게 하기
================================================

로컬 미리보기는 컴퓨터 속 그림 파일을 그대로 보여 줍니다.
배포 링크(script.google.com)는 그 그림 파일을 못 찾습니다.
그래서 Apps Script의 Index 에는 그림이 들어 있는 파일을 넣어야 합니다.

지금 폴더의 Index.html / 미리보기.html 이 그 파일입니다.
열어 보면 그림이 아주 긴 글자로 보이는데, 그게 정상입니다.

이미 배포한 링크를 고칠 때
--------------------------------
1. 예전에 만든 시트에서 확장 프로그램 → Apps Script
2. 왼쪽에서 Index 를 연다
3. 내용을 전부 지운다
4. 이 폴더의 미리보기.html 을 메모장이나 커서에서 연다
5. 전부 복사(Ctrl+A, Ctrl+C) 해서 Apps Script Index 에 붙여넣는다
6. Ctrl+S 로 저장한다
7. 위쪽 배포 → 배포 관리
8. 연필(수정) 누른다
9. 버전: 새 버전
10. 배포
11. 같은 링크를 연 다음 Ctrl+F5 로 새로고침한다

저장만 하고 새 버전 배포를 안 하면 링크는 예전 화면 그대로입니다.

처음 배포할 때
--------------------------------
1. https://sheets.new 로 새 시트를 연다
2. 확장 프로그램 → Apps Script
3. Code.gs 를 이 폴더의 Code.gs 로 바꾼다
4. + → HTML, 이름을 Index 로
5. 미리보기.html 을 전부 붙여넣고 저장
6. 배포 → 새 배포 → 웹 앱
   - 실행 계정: 나
   - 액세스 권한: 모든 사용자
7. 나온 URL을 쓴다
