이클립스 잠재력 — 변화 / 변주
============================

등급별 강화 최대 레벨
- 일반 Lv.20
- 고급 Lv.40
- 희귀 Lv.60
- 영웅 Lv.80
- 전설 Lv.100

확률: 일반 7.9% / 고급 3.5% / 희귀 1% / 영웅 0.08% / 전설 0.02%

옵션                      일반            고급            희귀            영웅             전설
일반공격 피해 증폭        0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
스킬 피해 증폭            0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
일반공격 피해 증폭 저항   0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
스킬 피해 증폭 저항       0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
PvP 피해 증폭             0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
PvP 피해 증폭 저항        0.4% / 7.9%     1.2% / 3.5%     2.4% / 1%       4% / 0.08%       6% / 0.02%
경험치 획득량 증가        0.33% / 7.9%    1% / 3.5%       2% / 1%         3.33% / 0.08%    5% / 0.02%
골드 획득량 증가          1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%

참고
- 변주는 일반공격/스킬/PvP 피해 증폭·증폭 저항과 경험치·골드 획득량. 옵션 8종.
- 피해 증폭·저항은 0.4%→1.2%→2.4%→4%→6% (태초 격앙 PvE 증폭, 충동 증폭 저항과 동일 배율).
- 경험치·골드는 태초 기세와 동일(0.33%→1%→2%→3.33%→5% / 1%→3%→6%→10%→15%).
