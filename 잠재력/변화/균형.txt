이클립스 잠재력 — 변화 / 균형
============================

등급별 강화 최대 레벨
- 일반 Lv.20
- 고급 Lv.40
- 희귀 Lv.60
- 영웅 Lv.80
- 전설 Lv.100

확률: 일반 7.9% / 고급 3.5% / 희귀 1% / 영웅 0.08% / 전설 0.02%

옵션                  일반            고급            희귀            영웅             전설
근거리 치명타 피해    1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%
원거리 치명타 피해    1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%
마법 치명타 피해      1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%
치명타 피해 감소      1% / 7.9%       3% / 3.5%       6% / 1%         10% / 0.08%      15% / 0.02%
최대 HP               500 / 7.9%      1500 / 3.5%     3000 / 1%       5000 / 0.08%     7499 / 0.02%
최대 MP               1600 / 7.9%     4800 / 3.5%     9600 / 1%       16000 / 0.08%    24000 / 0.02%
물약 최대 소지량      20 / 7.9%       40 / 3.5%       60 / 1%         80 / 0.08%       100 / 0.02%
MP 회복               20 / 7.9%       40 / 3.5%       60 / 1%         80 / 0.08%       100 / 0.02%

참고
- 균형은 근/원/마 치명타 피해·치명타 피해 감소와 HP/MP/물약/MP 회복. 옵션 8종.
- 치명타 피해·감소는 1%→3%→6%→10%→15% (1·3·6·10·15).
- 최대 HP/MP, 물약 최대 소지량, MP 회복은 태초 기세와 동일.
- 일반 최대 HP는 화면이 5000처럼 보이지만, 고급 1500 / 희귀 3000 / 영웅 5000 / 전설 7499
  및 1·3·6·10·15 배율에 맞춰 500으로 정리함.
- 영웅 최대 MP는 화면 표기가 1,6000, 전설은 2,4000으로 보임. 16000 / 24000으로 정리함.
- 전설 최대 HP는 화면 숫자 그대로 7499 (7500이 아님).
