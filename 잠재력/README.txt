이클립스 툴 — 잠재력
====================

가입절차와 별도인 잠재력 작업 폴더입니다.
이후 HTML·배포 작업도 이 폴더에서만 진행합니다.

태초 (6)
- 본능 / 직감 / 감각 / 격앙 / 충동 / 기세

변화 (6)
- 적응 / 유연 / 수용 / 변주 / 전조 / 균형

성찰 (6)
- 판단 / 관조 / 숙고 / 절제 / 분별 / 직시

시연 페이지
- Index.html / 미리보기.html / Code.gs / 사용법.txt
- 태초·변화·성찰을 가로로 배치한 방송용 툴
- 배포: 사용법.txt 대로 Apps Script에 Code.gs + Index.html 을 붙여넣는다
- 이미지는 Index.html 안에 들어 있어서 따로 올리지 않는다
- 로컬 확인은 미리보기.html 또는 http://127.0.0.1:8777/

데이터
- 태초 6개 + 변화 6개 + 성찰 6개
- 각 파일에는 등급별 최대 레벨, 옵션 8종, 최댓값, 확률이 들어 있습니다.
